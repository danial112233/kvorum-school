# Кворум · Курс

**Учебный поток прямо в Claude.** Каналы потока, задания со сдачей и проверкой, Claude как помощник куратора — в одном артефакте, который открывается в Claude на компьютере и телефоне.

Это школьная редакция [«Нашего чата»](https://github.com/danial112233/claude-nash-chat) — мессенджера-артефакта для тех, кто работает в Claude вместе. Сделана для онлайн-школ, которые учат работе с Claude и нейросетями: ученики общаются, сдают домашки и задают вопросы там же, где учатся.

Пробная версия. Интерфейс на русском. **English:** [README.en.md](README.en.md)

## Что умеет

- **Роли.** Преподаватель, куратор, ученик. Назначает преподаватель на вкладке «Команда».
- **Поток в одно нажатие.** «Настройки» → «Курс» создаёт каналы:
  - #объявления — пишут только преподаватели и кураторы;
  - #вопросы, #домашки, #флуд;
  - голосовой «Созвон» в Jitsi Meet.

  Там же учеников можно разбить на проектные группы по 2–5 человек.
- **Задания.** Скрепка → «Задание ученикам»: название, условие, критерии, срок. В ленте появляется карточка со сроком, счётчиком «Сдали 18 из 25» и кнопкой «Сдать».
- **Сдача.** Ученик отвечает на задание текстом, файлом, голосовым или кружком.
- **Проверка.** «Работы» на карточке показывают каждого ученика со статусом:
  - не сдано;
  - ждёт проверки;
  - сдано повторно;
  - проверено;
  - на доработке.

  Преподаватель ставит оценку и комментарий, ученик видит итог на карточке.
- **Первая проверка ИИ.** «Проверить ИИ» просит Claude преподавателя подготовить черновик оценки и отзыва по критериям. Без нажатия преподавателя ученик ничего не увидит.
- **Помощник куратора.** @claude отвечает по разделу «Программа курса». Если не знает или вопрос про оценки, сроки и личное, ставит метку «Нужен куратор».
- **Из Claude Code.** Скилл `kvorum-course` умеет:
  - выложить задание;
  - сказать, кто не сдал;
  - выгрузить оценки в CSV для Excel;
  - пополнить программу курса;
  - назначить роль.

## Что нужно школе

| | Общий аккаунт Claude | Claude Team, Enterprise или Claude for Education |
|---|---|---|
| Чат, задания, сдача, проверка, Claude | работает | работает |
| Роли | договорённость: роль может сменить любой | каждый входит под своим аккаунтом, доступ к артефакту выдаётся по ролям |
| Оценки | страница показывает их только ученику и преподавателям, но в базе их может прочитать любой участник | так же: база общая для всех, кому открыт артефакт |
| Ученики из другой организации | — | заходят гостями: читают всё, пишут текстом и голосовыми, сдают задания |

Полное разграничение ролей даёт только Claude Team, Enterprise или Claude for Education, где школа добавляет учеников в свою организацию. На общем аккаунте «Кворум · Курс» подходит для небольшого потока, где все свои.

## Быстрый старт

1. **Опубликуй страницу.** В Claude Code попроси: «опубликуй `page/nash-school.html` артефактом с возможностями db, room, user, assets, sample и downloads».
2. **Демо-данные (по желанию).** `python3 demo/make_seed.py` создаст `writes.json`. Попроси Claude Code записать его в базу артефакта одним пакетом. Получится поток с преподавателем Анной, куратором Олегом, четырьмя учениками, программой и заданием с двумя сданными работами.
3. **Открой артефакт.** Без демо-данных страница предложит «Настроить курс». С ними выбери себя из списка: Анна — преподаватель.
4. **Пригласи людей.** «Поделиться» → по почте. Доступ по ссылке оставь выключенным.
5. **Скилл (по желанию).** Скопируй `skill/kvorum-course` в `~/.claude/skills/` и замени `<ССЫЛКА_НА_ЧАТ>` на ссылку своего артефакта.

## Как устроено

Страница собирается из страницы «Нашего чата» (v28) одним патчем:

```
python3 patch/patch_school.py <claude-nash-chat/page/nash-chat.html> page/nash-school.html
```

Данные курса лежат в базе артефакта:

| Коллекция | Что в ней |
|---|---|
| `school/config` | название курса |
| `tasks` | задания |
| `subs` | последняя сдача каждого ученика по каждому заданию |
| `grades` | проверки |
| `people.role` | роли |

Сама работа — обычное сообщение с `reply` на задание и меткой `sub`. Формат полей — в `skill/kvorum-course/reference.md`, раздел «Школа».

Тесты (44 проверки в WebKit: преподаватель, ученик, пустой курс, гость, телефон):

```
cd tests && npm i playwright && npx playwright install webkit
python3 build.py && node school-test.js
```
